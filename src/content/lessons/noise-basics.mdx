Noise is a function that takes a position and returns a value that looks random but is not. The same input always produces the same output. That predictability is what makes it useful in shaders.

The useful mental model is:

```text
UV Coords → Corner Hash → Smooth Blend → Contrast → Output
```

## Visual Hook

<NoiseBasicsDemo />

The important idea is that smooth noise is just a hash with interpolation stacked on top:

- take a position in UV space
- hash the surrounding grid-corner coordinates to get random values
- smoothly blend between those corner values using a curve
- apply contrast or scale to taste

This is exactly what generates the grayscale mask in the dissolve lesson.

## What Each Step Does

**UV coordinates** are the input. Every pixel on a surface has a position. The noise function reads that position and nothing else.

**Cell hash** assigns a deterministic random value to each grid cell. It looks random but it is computed: the same coordinate always returns the same value. This is why noise can be pre-baked into a texture and reused.

**Smooth blend** interpolates between the four surrounding corner hashes using a smooth-step curve rather than a straight line. That curve is what makes the result look organic and soft instead of blocky.

**Contrast (roughness)** pushes values toward the extremes. Low roughness gives soft, almost-uniform blobs. High roughness gives sharp, crunchy edges.

**Scale** zooms in or out of the noise field. Higher scale packs more cells across the surface — finer grain. Lower scale spreads fewer cells — bigger, bolder shapes.

## Three Useful Presets

- **Organic:** wide, soft blobs — useful for clouds, smoke, and large dissolve mask areas.
- **Gritty:** high scale and contrast — useful for rust, surface grit, and noise overlays.
- **Ripple:** smooth at medium scale — useful for water surfaces and flowing energy.

## How This Connects

The other shader lessons in this vault all depend on grayscale input values. Noise is the most common way to generate those values:

- The <LessonLink slug="uv-dissolve-shader">dissolve lesson</LessonLink> uses a noise mask to decide which pixels disappear.
- The <LessonLink slug="masked-color-ramp">masked color ramp</LessonLink> takes a grayscale value and maps it to color — noise provides that value.
- The <LessonLink slug="uv-panning-flow-maps">flow maps lesson</LessonLink> pans UVs across a noise-like texture to simulate motion.

Once you can read a noise pattern as a mask or a value, the other lessons become a question of what you do with that value next.

## Common Mistakes

- Confusing scale with resolution. Higher scale does not add more detail — it cycles the same function faster.
- Thinking the output changes each frame. It does not unless the UV input changes over time (which is how animated noise works).
- Expecting a real noise texture from this page. This is conceptual only; no `.png` asset is generated.

## Shader Graph Equivalent

In Unity Shader Graph, this whole pipeline is a single **Simple Noise** node —
its internal hash-and-smooth-blend is exactly the corner hash and smooth blend
above — with the **Scale** input as your scale. Follow it with a **Contrast** (or
**Power**) node for roughness. **Gradient Noise** is the Perlin-style variant.
This page teaches the node wiring only; it does not generate a real `.shadergraph`
asset or noise texture.
