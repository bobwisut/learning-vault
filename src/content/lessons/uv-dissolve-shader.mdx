A dissolve shader uses a grayscale pattern to decide which parts of a surface stay visible and which parts disappear.

The useful mental model is:

```text
UV → Noise → Threshold → Alpha Cutoff → Edge Glow → Final Color
```

## Visual Hook

<DissolveShaderDemo />

The important idea is that the final dissolve is not one mysterious operation.
It is several small decisions stacked together:

- sample a noise value
- compare it to a cutoff
- hide one side of the comparison
- color the values close to the cutoff

## Concept Map

<FlowCanvas steps="UV|Noise|Threshold|Alpha Cutoff + Edge Glow|Final Color" />

## What Each Step Does

**UV** is the surface coordinate. It tells the shader where on the mesh it is sampling.

**Noise** gives each point on the surface a grayscale value.

**Threshold** compares each noise value to the cutoff slider. Lower cutoff means more of the surface survives. Higher cutoff means more disappears.

**Alpha cutoff** hides pixels below the threshold.

**Edge glow** colors the thin band near the cutoff, which makes the disappearing border readable.

## Three Useful Presets

- **Soft edge:** a wider glow band for magical or energy-style dissolves.
- **Crisp cut:** a small edge band for hard digital breakup.
- **Almost gone:** a high cutoff where only bright noise islands remain.

## Common Mistakes

- Using noise without UV control, which makes the pattern hard to direct.
- Making the edge band too wide, which turns the dissolve into a blob of glow.
- Forgetting that this web lesson is conceptual; it is not an actual Unity Shader Graph asset.

## Shader Graph Equivalent

In Unity Shader Graph, this maps to a **Simple Noise** node feeding a **Step**
node (the Edge input is your dissolve threshold), wired into **Alpha** with
**Alpha Clip Threshold** enabled in the Graph Settings. The edge glow is a thin
band — a **Smoothstep**, or the difference of two Steps, around the threshold —
multiplied by a color into **Emission**. This page teaches the node wiring only;
it does not generate a real `.shadergraph` asset.

## Practice

Set the demo to **Soft edge**. Move only the alpha cutoff slider and watch the four panels. Then write one sentence:

```text
The raw noise stays the same, but the threshold mask changes by ____.
```

After that, move only the edge width slider and describe what changes in the edge band.
