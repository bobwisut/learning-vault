A dissolve shader decides which parts of a surface stay visible and which parts disappear.

The useful mental model is:

```text
UV -> Noise -> Threshold -> Alpha Cutoff -> Edge Glow -> Final Color
```

## What Each Step Does

**UV** is the surface coordinate. It tells the shader where on the mesh it is sampling.

**Noise** turns those coordinates into an uneven grayscale pattern.

**Threshold** compares the noise value to a cutoff value. Lower cutoff means more of the surface survives. Higher cutoff means more disappears.

**Alpha cutoff** hides pixels below the threshold.

**Edge glow** colors the thin band near the cutoff, which makes the disappearing border readable.

## Three Useful Presets

- **Soft edge:** a wider glow band for magical or energy-style dissolves.
- **Crisp cut:** a small edge band for hard digital breakup.
- **Almost gone:** a high cutoff where only bright noise islands remain.

## Common Mistakes

- Using noise without UV control, which makes the pattern hard to direct.
- Making the edge band too wide, which turns the dissolve into a blob of glow.
- Forgetting that this web lesson is conceptual; it is not an actual Unity Shader Graph or ASE asset.
