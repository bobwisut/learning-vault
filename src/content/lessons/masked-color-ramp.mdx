The useful mental model is:

```text
Grayscale Mask → Ramp Stops → Color Lookup → Final Color
```

## Visual Hook

<MaskedColorRampDemo />

The important idea is that color is not painted per pixel by hand. A single grayscale
value picks a spot on the ramp, and the ramp returns the final color:

- read one grayscale value
- find where it sits between the stops
- blend the two surrounding colors
- output that color

## What Each Step Does

**Grayscale mask** is the input. Each pixel has a single value from dark to bright.

**Stop positions** decide where the low, mid, and high colors take over. Move a stop and the same mask reads completely differently.

**Banded zones** show the hard version: which of the three colors a value would snap to without blending.

**Color lookup** is the smooth version: values between two stops blend between the two colors.

**Final color** is just the lookup applied to the whole surface. No extra work.

## Three Useful Presets

- **Lava:** dark rock at the bottom, glowing orange edge, hot bright core.
- **Toxic:** deep green base ramping into an acid-green highlight.
- **Ice:** cold shadow tones lifting into bright frozen highlights.

## Common Mistakes

- Pushing both stops close together, which removes the blend and posterizes the result.
- Forgetting that the mask never changed; only the mapping did.
- Thinking this web lesson exports a real ramp texture; it is conceptual only.

## ASE Equivalent

In Amplify Shader Editor, this is a grayscale value feeding a gradient or ramp node
(often a ramp texture sampled by the mask). This page teaches the mapping logic only;
it does not generate a real ASE graph or ramp texture asset.

```text
The grayscale mask stays the same, but the bright color now covers ____.
```
