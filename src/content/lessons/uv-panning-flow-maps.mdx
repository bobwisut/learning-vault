UV panning is one of the simplest ways to make a texture feel alive. A flow map
adds the next idea: local bends that make the motion curve instead of sliding in
one perfectly straight direction.

<FadeIn delay={0.1}>
  Instead of moving the mesh, the shader moves where it samples the texture.
  The surface stays still, but the pattern slides across it.
</FadeIn>

The useful mental model is:

```text
UV → Offset Time → Optional Flow Bend → Texture Sample → Final Color
```

## What Each Step Does

**UV** is the original texture coordinate on the surface.

**Offset time** adds a changing value to the UV. That changing value creates motion.

**Optional flow bend** nudges the moving UVs locally. A real flow map stores
those local directions in a texture; this lesson uses a web distortion to show
the idea conceptually.

**Texture sample** reads the texture at the shifted coordinate.

**Final color** shows the sampled result on the surface.

## Three Useful Presets

- **Water drift:** slow sideways motion for water, mist, or heat haze.
- **Energy stream:** fast vertical movement for shield or magic effects.
- **Smoke crawl:** slow diagonal movement for smoke, dust, or clouds.

## How This Connects

- The <LessonLink slug="two-layer-uv-panning">two-layer panning lesson</LessonLink> stacks two of these panners at different speeds for richer, less repetitive motion.
- The texture being scrolled is often a <LessonLink slug="noise-basics">noise pattern</LessonLink> — panning noise is how you get drifting smoke, water, and energy.
- Pan a <LessonLink slug="uv-dissolve-shader">dissolve mask</LessonLink> and the dissolve edge moves across the surface instead of staying fixed.

## Common Mistakes

- Panning too fast, which makes the surface look like a screen instead of material.
- Moving only one layer, which can feel flat; later lessons can stack two panners.
- Forgetting that this is conceptual web teaching, not a real Unity Shader Graph asset.

## Shader Graph Equivalent

In Unity Shader Graph, panning is a **Tiling And Offset** node whose **Offset**
is **Time** multiplied by your direction vector, feeding the UV of a **Sample
Texture 2D** into **Base Color**. The flow bend adds a flow (or normal) texture:
sample it, remap to -1..1, and add it into that offset so the motion curves
locally. This page teaches the node wiring only; it does not generate a real
`.shadergraph` asset or flow-map texture.
